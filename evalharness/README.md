# Gateway-Harness Evaluation Harness

The Evaluation Harness simulates realistic production workloads across 6 archetypes:
1. Classification & Intent Detection
2. Structured JSON Information Extraction
3. Long-form Summarization & TL;DR
4. Multi-lingual Translation
5. Context-grounded Q&A (RAG)
6. Enterprise Drafting & Content Generation

### Quick Start:
```bash
python -m evalharness.run_eval
```
